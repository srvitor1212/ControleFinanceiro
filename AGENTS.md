# Controle Financeiro

## Objetivo

Um aplicativo para registar e controlar as dividas pessoais. 

## Estrutura dessa solução

A solução tem várias micro serviços que compem o produto final.

Cada serviço está separado em sua pasta, hoje existem:
- O frontend é um PWA localizado em `Frontend/`.
- O backend é uma API localizada em `Api/`
